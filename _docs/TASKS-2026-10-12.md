## Decisions taken where the directive left room

| Topic | Decision |
|---|---|
| "Verified Room" (image) vs "Premium Room" (§4) | **Premium Room** is the name. It carries a "Deriv Verified" badge. Market Rooms (one per pair, platform-owned) stay as they are. |
| Individual "max 1 Deriv account" | One Deriv **login** (one OAuth connection). Its sub-accounts (USD, MT5…) still show under it. Institutions: up to **20** connections. |
| Performance Points (§7) | Forex & metals: 1 point = 1 pip (pip size per instrument). Every other market: 1 point = a 0.01 % move from entry (1 basis point), so V75, Boom, crypto and indices are comparable. Stored separately from KX Points. |
| Creator commission (§14) | Configurable by Super Admin; shown as **"provisional — to be finalised"**. Default 20 % for the prototype. |
| KX Points cost to post a signal | Small and configurable (default 5 pts per signal, refunded if the signal is rejected by validation). Starter grant on first qualifying achievement so legitimate providers are not blocked. |
| Rewards page | Becomes the **KX Points** page (earn, spend, history, anti-abuse note). |

## Cross-agent contracts (build against these; guard with `if (MB.x)`)

```js
// Agent 3 — assets/js/core/kx.js
MB.kx.balance()                                   // -> number (KX credits)
MB.kx.spend(amount, { type, ref, label })         // -> Promise<{ ok, balance, txn }>, rejects Error('insufficient')
MB.kx.points.balance()                            // -> number
MB.kx.points.cost(action)                         // 'signal_post' | 'boost' -> number
MB.kx.points.spend(action, { ref })               // -> { ok, balance } | { ok:false, reason }
MB.kx.points.refund(action, { ref })
MB.kx.points.award(event, { ref })                // -> { awarded, reason }  (anti-abuse inside)
MB.kx.privileges()                                // -> { can_post_signals, reasons:[], unlocked_by:[] }

// Agent 2 — signal-tracker.js / signal-composer.js
MB.signalComposer.open({ market, room, onPublished })   // market locks the pair when given
MB.signalTracker.add(draft) / .list(filter) / .get(id) / .stats(filter) / .on(fn)
MB.signalTracker.toMessageSignal(sig)             // shape MB.card.message renders in chat
MB.signalTracker.points(sig)                      // performance points earned

// Agent 1 — disclaimers.js
MB.disclaimer.require(key)                        // 'trade'|'signals'|'community'|'paid_room' -> Promise (resolves once accepted)
```
