Signal Disputes

Automated results that a user has disputed, for moderator review

How a result is decided

  • A signal becomes active only when price reaches its entry. Not reached in 24h → Expired.
  • TP1 before SL = WIN, permanently. A later return to the stop never changes it; TP2–TP5 only add points.
  • SL before TP1 = LOSS. Both levels inside one tick → resolved against the author.
  • Community opinion never overrides the system, and outcomes are never voted on.
  • A reviewer may only Uphold the automated result or Correct it when the data was wrong (e.g. an invalid tick).
  • Both actions need a written reason and are recorded in the dispute's audit log.
